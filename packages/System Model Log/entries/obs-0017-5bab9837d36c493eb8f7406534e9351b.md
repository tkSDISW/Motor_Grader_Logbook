### I_19 integrity errors — fixed (commit `a275fe9f`, model repo `https://github.com/tkSDISW/Motor_Grader/`, branch `master`)
User reported four Capella integrity validation errors:

1. **`Steer Machine` — 5 duplicate `outSteering Input` ports.** Root cause: the function fans out to 5 grading functions (Grade Road Surface, Shape Shoulder, Shape Slope, Rip and Scarify Hardened Ground, Clear Snow) via 5 functional exchanges all named `Steering Input`; Capella auto-derives each port's name from its exchange, so all 5 got the identical auto-generated name. Fixed by renaming each port to include its target, e.g. `outSteering Input (Grade Road Surface)`.
2. **`Control Blade Position` — 5 duplicate `outBlade Position Input` ports.** Same root cause and fix pattern.
3. **`Control Direction of Travel` — 5 duplicate `outDirection Input` ports.** Same root cause and fix pattern.
4. **`Motor Grader` — 2 components named `Information Solutions`.** This is the previously-flagged orphaned duplicate. **Not fully resolved** — this tool has no delete capability, so the orphaned empty one was renamed to `Information Solutions (DUPLICATE - pending deletion)` with a description explaining why, which clears the naming-collision error but leaves the dead component in place. User needs to delete it manually in Capella Studio.

`verify_model` on SA and LA: 0 findings (note: this tool's own checks — missing names, unallocated functions — didn't catch the I_19 duplicate-sibling-name issue in the first place; that requires Capella Studio's own validation, which is what surfaced it).
