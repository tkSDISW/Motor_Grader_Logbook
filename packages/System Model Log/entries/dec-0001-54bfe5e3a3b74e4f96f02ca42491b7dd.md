### Notes on the process
- The model repo was completely empty (no elements at all), so the standard `browse_model`/`search_model_objects` read tools couldn't surface the root package UUIDs needed as patch parents — there was nothing to browse yet. Resolved by cloning the public repo directly via `bash`/`git` and parsing the raw `.capella` XML to find the `EntityPkg` and `OperationalCapabilityPkg` UUIDs under the model's default `OperationalAnalysis` architecture.
- First push attempt failed — the initial `clone_capella_repo` call was made without a PAT (repo is public for read), which is sufficient for reading but not for pushing. Re-cloned with a PAT to get write access, reapplied the identical patch (the failed session's commit never reached the remote, so no duplication occurred), verified via `browse_model`, then pushed successfully.
