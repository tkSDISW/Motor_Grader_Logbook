## Unified "Operate" Functional Chain — Major LA Expansion

### Context
User built out a substantial new functional architecture in Capella Studio implementing the unified "Operate" chain concept discussed earlier: rather than five parallel per-capability functions each independently commanding the blade, a single chain now flows from operator input through management/actuation functions down to a shared power/hydraulic distribution tree.

### New structure discovered (via fabric pull of [LAB] Structure, 215 objects)
**New logical components:** Hydraulic System, Steering Control Subsystem, Super Structure (in addition to the 9 from the earlier decomposition).

**New logical functions forming the Operate chain:**
- `Accept Operator Commands` (Operator Cabin) — receives Steering/Blade Position/Direction input from the operator's existing OA-derived activities (Steer Machine, Control Blade Position, Control Direction of Travel).
- `Determine Blade Adjustment` (Grade Control System), `Manage Direction of Travel` (Direction Control System), `Manage Steering` (Steering Control Subsystem) — the three management/decision functions.
- `Deliver Moldboard Capability` (Blade System), `Deliver Steering` + `Deliver Camber` (Steering System), `Deliver Traction` + `Deliver Power` (Engine and Powertrain System), `Deliver Attachment Capability` (Attachment Subsystem), `Deliver Hydraulic Pressure` (Hydraulic System) — the actuation/distribution layer, with a shared hydraulic pressure source feeding steering, camber, moldboard, and attachment actuation.
- `Supports Subsystems` (Super Structure) — a status/telemetry aggregation function receiving feedback from every other function in the chain (12 inputs currently, no outputs yet — flagged as open item below).
- `Undergo Surface Modification` (Worksite Environment) — confirmed still allocated as the terminal effect function from the earlier session.
