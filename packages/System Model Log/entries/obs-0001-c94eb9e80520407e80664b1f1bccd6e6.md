## CAT 120 Motor Grader — Operational Capabilities Research

Researched via web search (Caterpillar's own product page for the current Tier 4 / Stage V 120 model, plus secondary spec aggregators) ahead of building the OA layer of the Capella model.

### Core operational capabilities
- **Road grading, shoulder shaping, slope shaping** — the machine's primary stated purpose.
- **Fine/finish grading with grade-control assistance** — Cross Slope, Cross Slope Indicate, and Digital Blade Slope Meter options; an Attachment-Ready Option (ARO) allows further grade-control tech to be integrated.
- **Bounce-compensated grading (Stable Blade)** — an optional feature that automatically slows the machine if blade bounce would degrade grade accuracy, reducing manual rework.
- **Ripping / scarifying hardened ground** — via optional multi-shank ripper/scarifier attachments (straight or V-shape mid-machine scarifier).
- **Snow and material clearing** — via optional snow wing attachment.
- **All-wheel drive traction mode** — optional AWD for better traction/maneuvering, net power range 145–189 hp in that configuration.
- **Operator blade control** — steering wheel/lever or joystick control options from the cab.

### Supporting (fleet/off-board) capabilities — likely a separate operational actor, not on-board
- **VisionLink** — cloud telematics for fleet monitoring and productivity tracking.
- **Remote Flash / Remote Troubleshooting** — dealer-initiated remote software updates and diagnostics.

### Key specs (current-generation 120, Tier 4 Final / Stage V)
- Net power: 174 hp (128 kW) — Cat C7.1 engine
- Operating weight (typically equipped): ~37,106 lb (16,831 kg)
- Blade (moldboard) width: 12 ft (3.7 m), with optional 24 in extension
- Transmission: 9 forward / 6 reverse, direct-drive powershift
- Fuel tank: 65 gal (246 L); DEF tank: 3 gal (11 L)

### Modeling implication
These map fairly directly to candidate OA-layer Operational Activities (grade a road surface, shape a shoulder, shape a slope, rip/scarify hardened ground, clear snow) and an Entity/Actor split between the on-board operator role and an off-board fleet-management actor (VisionLink/dealer remote services). Proposing we start OA modeling from this list next.

**Sources:** cat.com product page for the 120 (current gen), constructionequipment.com, veritread.com, heavyhaulers.com (secondary spec aggregators, used for cross-checking dimensions/weight only).
