## PMEI Prefix Pass Applied to All Component Exchanges

### Context
Following decision `dec-0003` (adopt PMEI prefix convention for Component Exchange names), did a full pass over every Component Exchange in the model — both SA and LA layers — classifying each by DSM category and applying the `[X] Name` prefix.

### Classification results (commit `3a18be31`, model repo `https://github.com/tkSDISW/Motor_Grader/`, branch `master`)
27 total Component Exchanges (7 SA-layer, 20 LA-layer):

**[I] Information (21):** all operator/control-command signals and requests — `Telematics Data`, `Remote Support Channel`, `Blade Adjustment Commands`, `Service Request` (each duplicated at SA and LA), `Steering Control`, `Blade Position Control`, `Direction Control` (each duplicated at SA and LA), `Steering Command Channel`, `Blade Command Channel`, `Direction Command Channel`, `Steering Actuation Channel`, `Moldboard Actuation Channel`, `Drivetrain Request Channel`, `Attachment Actuation Channel`.

**[E] Energy (6):** exchanges carrying actual force/power/pressure — `Blade-Ground Contact`, `Front Wheel-Ground Contact`, `Rear Wheel-Ground Contact`, `Mechanical Power Channel`, `Hydraulic Pressure` (×2, Blade System and Steering System legs).

**[P] Physical and [M] Material: none yet.** No pure structural/mounting connections or bulk fluid/consumable flows (fuel, coolant, DEF) exist in the model currently — natural candidates for these categories if/when those subsystems get modeled.

`verify_model` on both SA and LA: 0 findings.

### Flagged, not fixed
Two LA-level Component Exchanges carry **no allocated functional exchange** — likely orphaned leftovers from the SA→LA transition, superseded by newer named paths:
- `[I] Blade Adjustment Commands` (Attachment Subsystem → Worksite Environment)
- `[I] Service Request` (Road Maintenance Organization → Motor Grader)

Both were still given the PMEI prefix per their existing names, but flagged for the user to decide whether to clean up/remove as dead structure.

### Convention going forward
All new Component Exchanges should be named with the `[P]`/`[M]`/`[E]`/`[I]` prefix per `dec-0003` at creation time, rather than retrofitted later.
