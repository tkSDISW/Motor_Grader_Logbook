This package tracks activity related to the Motor Grader Capella system model as it's being built — decisions made during modeling, observations about the model's structure or scope, and lessons learned along the way.

**Scope note:** this log book captures the *narrative* around the model (why choices were made, what changed and why, open questions). The Capella model itself lives in its own separate repository and is accessed/modified via the `capella-fabric` MCP server, not here.
