## LA Layer Started — Logical Component Decomposition

### Context
Began the Logical Architecture layer for the Motor Grader model. Researched Cat 120/120 GC technical specifications (Caterpillar's official spec sheet AEXQ3334-04, plus Cat Grade/Cross Slope Assist product pages) to ground the logical decomposition in real subsystems rather than guessing at structure.

### Key research findings (for reference)
- **Engine**: Cat C4.4, 115-128 kW net, powershift transmission (6F/3R on 120GC, 9F/6R on standard 120).
- **Hydraulic system**: closed-center, variable piston pump, 0-155 L/min, 24,150 kPa.
- **Steering**: front axle max 47.5°, frame articulation 20° L/R, metering pump-driven.
- **Blade/moldboard actuation**: 2 lift cylinders, circle center shift cylinder, moldboard side-shift cylinder, blade tip cylinder, 64-tooth circle drive (360° rotation).
- **Grade Control (Cat Grade with Cross Slope Assist)**: blade-mounted slope sensors, factory-integrated display, "Cross Coupling" control software, standard electro-hydraulic circuit for automatic corrections.
- **Telematics**: confirmed the actual onboard hardware is branded **Product Link**, feeding the off-board **VisionLink** service (which is what our `Fleet Manager` actor's activities correspond to).
- **Attachments**: ripper (5 shank holders, 286mm max depth), rear scarifier (9 shanks, 251mm max depth, 2292mm width).

### Design note
Split the operator-facing "input" side (Operator Cabin) from several actuation-side systems (Steering System, Direction Control System, Blade Actuation System) since in a real machine the operator's controls and the physical actuation mechanisms they command are distinct components connected by a component exchange, not the same part.
